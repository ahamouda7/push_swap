## 📌 Description

#### 🎯 Goal

The objective of **push_swap** is to sort a stack of integers using a limited set of operations and the smallest possible number of moves.

This project focuses on:

- Algorithm optimization
- Time and space complexity
- Data structure manipulation
- Efficient sorting strategies

The program must output the smallest sequence of valid instructions that sorts the input stack.

---

#### 🧠 Overview

`push_swap` takes a list of integers as arguments and sorts them in ascending order using two stacks:

- **Stack A** (initial stack containing random integers)
- **Stack B** (initially empty)

You are restricted to a predefined set of operations and must determine the most efficient algorithm to sort the numbers.

The program prints the list of operations to `stderror`.

> **Bonus Feature:** You can also pipe `push_swap` output to the checker program (`checker_OS`) to validate that your sorting sequence works correctly.

---

#### ⚙️ Available Operations

You may only use the following instructions:

###### 🔄 Swap Operations
- `sa` – Swap the first two elements of stack A
- `sb` – Swap the first two elements of stack B
- `ss` – Execute `sa` and `sb` simultaneously

###### 📤 Push Operations
- `pa` – Push the top element from stack B to stack A
- `pb` – Push the top element from stack A to stack B

###### 🔁 Rotate Operations
- `ra` – Shift all elements of stack A up by one
- `rb` – Shift all elements of stack B up by one
- `rr` – Execute `ra` and `rb` simultaneously

###### 🔃 Reverse Rotate Operations
- `rra` – Shift all elements of stack A down by one
- `rrb` – Shift all elements of stack B down by one
- `rrr` – Execute `rra` and `rrb` simultaneously

---

#### 🚀 Sorting Strategy

Different strategies can be used depending on the dataset size:

###### 🔹 Small Datasets (≤ 5 numbers)
- Hardcoded minimal sorting sequences.

###### 🔹 Medium/Large Datasets (100–500 numbers)
Common approaches include:

- Radix Sort (binary-based indexing)
- Chunk-based sorting
- Turk Algorithm
- Cost-based insertion strategy

###### 📊 Performance Benchmarks (42 Subject)

To achieve maximum score:

- ≤ 700 moves for 100 numbers
- ≤ 5500 moves for 500 numbers

---

#### 🧩 Checker Strategy

The **checker_OS** program is used to validate the sequence of operations generated by `push_swap`. Its main responsibilities include:

- Reading the initial stack of integers.  
- Applying the sequence of operations (`sa`, `pb`, `ra`, etc.) provided by `push_swap`.  
- Checking if **Stack A** ends up sorted in ascending order and **Stack B** is empty.  
- Printing `OK` if the stack is correctly sorted, or `KO` if the sequence failed.

#### ▶ Usage

```bash
./push_swap 2 1 3 6 5 8
```

Example output:

```
pb
sa
ra
pa
```

Test with checker:

```bash
ARG="4 67 3 87 23"; ./push_swap $ARG | ./checker_OS  $ARG
```

Test bonus:

```bash
./push_swap 4 67 3 87 23 | ./checker 4 67 3 87 23
```

- If the program works, it prints:

    ```
    OK
    ```

- Otherwise, it prints:

    ```
    KO
    ```
